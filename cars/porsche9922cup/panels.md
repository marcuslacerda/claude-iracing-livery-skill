## Spec map — the template's default values (layer "Custom Spec Map")

- R (metallic) Base Paint = 0; G (roughness) Base Paint = 33 (very glossy); B ("Clearcoat" in the PSD) = 0;
  Alpha = 255 on the paint, 0 on the mechanical parts. The "Parts" layer overrides unpainted parts (carbon ≈ G 127).
- For a "matte logo": raise G to ~170–200 only under the logo, keep 33 on the body.
